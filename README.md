# E-commerce Sales Analytics

In this portfolio project, I built an end-to-end sales analytics solution for an e-commerce store using SQL, Python, and Tableau.

### Project Goals
- Extract and prepare data from Google BigQuery using SQL
- Perform exploratory and statistical analysis in Python
- Build interactive dashboards in Tableau

### Project Deliverables
- Jupyter Notebook with:
  - data extraction and preprocessing
  - exploratory data analysis (EDA)
  - statistical analysis and visualizations
- Interactive Tableau Public dashboard

### Key tech areas
- SQL querying and data extraction
- Data analysis with Python (Pandas, NumPy, Matplotlib/Seaborn)
- Statistical analysis and hypothesis testing
- Data visualization and dashboard development in Tableau
- Business insight generation and reporting
